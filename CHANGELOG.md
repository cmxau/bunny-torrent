# Changelog

## 0.1.0

First release.

- Add torrents by magnet, file or drag and drop; magnet-link handler with a preview popup and per-file priority.
- Sidebar filters (status, categories, tags, trackers), selectable columns and per-torrent details.
- Default Video / Picture / Music / Other folders with automatic sorting.
- Overview page with cards, speed chart and online search with history.
- Download queue, seeding rules, speed-limit schedule and optional IP blocklist.
- Tray icon, close-to-tray, start with Windows and completion notifications.
- Create torrent, watch folders and RSS auto-download with filters.
- Signed automatic updates from GitHub releases.
